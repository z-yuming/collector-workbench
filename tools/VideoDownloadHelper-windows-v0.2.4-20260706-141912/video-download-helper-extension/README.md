# 视频下载助手

一个用于电脑 Chrome/Edge 的视频下载扩展，需要配合本地服务使用。

## 当前能力

- 自动发现网页里的视频资源
- 优先筛选当前正在播放的主视频
- 展示缩略图、时长、分辨率和来源标签
- 一键下载并尽量合成完整 MP4
- 按“博主名_发布日期”命名成品文件
- 下载完成后打开文件所在位置

## 加载方式

1. 打开 `chrome://extensions/`
2. 打开右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择扩展目录

Mac 分享包里应选择：

```text
video-download-helper-extension
```

## 使用方式

1. 先启动本地服务
2. 打开目标网页并播放视频
3. 点击浏览器右上角“视频下载助手”
4. 点击视频行里的“下载”

## 注意

- 不处理 DRM 或加密版权保护内容
- 部分网页需要先播放几秒，插件才能抓到完整资源
- 如果列表为空，可以先点“刷新”或“探测”
